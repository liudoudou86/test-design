# Analyze 模板

## 模板结构

```markdown
# Analyze: [功能名称]

## 1. 需求来源
- 来源类型：PRD / Jira / 功能描述
- 来源标识：[Jira编号 / 文档链接 / 口头描述]
- 获取方式：[脚本运行结果 / 用户提供]

## 2. 功能概述
- 一句话描述
- 目标用户
- 业务价值

## 3. 核心功能点

| # | 功能点 | 优先级 | 简要描述 |
|---|--------|--------|----------|
| 1 | 功能A | P0 | 描述 |
| 2 | 功能B | P1 | 描述 |
| 3 | 功能C | P2 | 描述 |

## 4. 关键假设

- 假设1
- 假设2

## 5. 边界条件与约束

### 数据约束
- 输入长度限制
- 数据类型限制
- 可选/必填字段

### 环境约束
- 浏览器/OS兼容性
- 依赖的外部系统
- 性能指标要求

### 权限约束
- 用户角色
- 权限层级

## 6. 待澄清问题

- [ ] 问题1（请确认）
- [ ] 问题2（请确认）

## 7. 确认状态

- [ ] 用户已确认分析结果
```

## 填写指南

### 核心功能点
- 标记优先级：P0（必须测试）/ P1（重要测试）/ P2（可选测试）
- 每个功能点对应一个独立可测的单元

### 关键假设
- 列出AI根据模糊描述所做的推断
- 用户确认前，假设可能不准确

### 边界条件
- 数据层面：空值、超长、特殊字符、重复数据
- 环境层面：网络异常、超时、并发
- 权限层面：未登录、无权限、越权
