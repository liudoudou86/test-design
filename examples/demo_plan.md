# Plan: 用户登录注册系统

## 1. 概述

- 需求来源：Analyze: 用户登录注册系统
- 版本号：v1.0
- 编写日期：2024-01-15

## 2. 测试范围

### In Scope（本次测试）

- 用户注册（邮箱注册）
- 用户登录（邮箱登录）
- Token 认证（JWT）
- 修改昵称
- 修改头像

### Out of Scope（本次不测试）

- 手机号登录/注册
- 第三方登录（微信、Google）
- 密码找回
- 用户权限体系

## 3. 测试类型与策略

| 测试类型 | 覆盖级别 | 方法说明 |
|----------|----------|----------|
| 功能测试 | 全覆盖 | 边界值、等价类、场景法 |
| UI/UX | 核心流程 | 注册/登录页面的视觉与交互检查 |
| 兼容性 | 主流浏览器 | Chrome/Firefox/Safari/Edge |
| 性能 | 关键接口 | 注册/登录 API 响应时间<200ms |
| 安全 | 高风险点 | Token 安全、密码加密、越权访问 |

## 4. 测试环境

| 环境 | 配置 | 用途 |
|------|------|------|
| 本地开发 | Node 18 + MySQL 8 | 功能验证 |
| 测试环境 | Docker 部署 | 全量测试 |
| 预发布 | 生产配置 | 回归验证 |

## 5. 测试数据

- 正常用户：正确邮箱 + 符合规范的密码
- 异常数据：错误格式邮箱、短密码、超长昵称
- 边界数据：空值、特殊字符、超长字符串
- 头像文件：jpg/png 正常文件、超过2MB文件、非图片文件

## 6. 工具与框架

| 工具 | 用途 |
|------|------|
| Postman | API 接口测试 |
| Selenium | 端到端流程测试 |
| Lighthouse | 性能审计 |

## 7. 风险与缓解措施

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|----------|
| 密码安全 | 高 | 低 | bcrypt 加密，不记录明文密码 |
| Token 泄露 | 高 | 中 | HTTPS 传输，7天过期 |
| 并发注册冲突 | 中 | 低 | 数据库唯一索引保证 |
| 头像存储 | 中 | 低 | 云存储 + 文件类型校验 |
